# Amazon India Sales Dashboard

## Project Overview

An Excel dashboard for reviewing Amazon India sales performance, profit,
order status, category/product performance, payment methods, fulfilment
methods, and state-wise results.

## Tools

-   Microsoft Excel
-   Excel formulas
-   PivotTables and PivotCharts

## Dataset

The supplied dataset contains 10,000 records dated from 1 January 2024
to 30 August 2026. Fields include Order_ID, Order_Date, Category,
Product, Quantity, Unit_Price_INR, Discount_Pct, Total_Sales_INR,
Profit_INR, Payment_Method, Fulfillment, Order_Status and Ship_State.

-   Order_ID records counted: 10,000
-   Total Units Sold: 24,926

-   Profit Margin: 21.29%
-   Returned records: 485
-   Cancelled records: 500
-   Return Rate: 4.85%

Note: these reported calculations include all rows/statuses. Confirm
Order_ID uniqueness before describing the count as distinct orders.

## Dashboard Analyses

1.  Monthly Sales and Profit Trend

## Workbook Sheets

`Raw_Data`, `KPI_Summary`, `Pivot_Analysis`, `Charts`, `Dashboard`

## How to Use

Open the workbook in Microsoft Excel and select the `Dashboard` sheet.
Inspect supporting PivotTables in `Pivot_Analysis`. Refresh PivotTables
after updating source data and check formulas before presenting updated
results.
